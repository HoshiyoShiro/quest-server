add one a single entry
a category typed as Parent > Child creates both if they do not exist yet. transfers move between your own accounts and count as neither income nor expense.
bulk insert paste a batch, check it, then commit
one entry per line: date, account, category, amount, note — comma or tab separated. a negative amount is an expense and a positive one is income, the way a statement already reads. drop the date to use today. lines starting with # are ignored.
accounts anywhere money sits
the opening balance is what was already in there before this ledger started. archiving keeps an account's history but takes it out of the pickers and the net worth total.

data
export downloads everything for this profile as JSON. import replaces this profile's data with a previously exported file (server keeps 7 daily backups as safety net).
ledger data the money side, on its own
the JSON export round-trips accounts, categories and entries. importing asks whether to replace the ledger or merge into it — a merge matches on name and gives every entry a fresh id, so importing the same file twice duplicates rows rather than silently overwriting them. the CSV export writes whatever the ledger's entries filter is currently showing; to go the other way, paste CSV into bulk insert.
